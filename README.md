## Задание

Для варианта № 11 разработан класс «Студент» с полями: ФИО, группа, номер зачетной книжки и четыре оценки за сессию. Исходный контейнер — `vector`, копирование выполняется в `deque` с помощью `std::copy`, сортировка исходного `vector` выполняется по возрастанию среднего балла с помощью `std::sort`.

## Состав проекта

- `main.cpp` — основная программа;
- `student.h`, `student.cpp` — класс `Student`;
- `input.txt` — исходные данные;
- `output.txt` — результат работы программы (создается при запуске);
- `CMakeLists.txt` — настройки сборки CMake.

## Сборка и запуск

Откройте эту папку в CLion как отдельный проект. CLion автоматически обнаружит `CMakeLists.txt`.

Программа читает `input.txt` из рабочей директории. В CLion проверьте, что **Working directory** установлен в корень проекта (`$PROJECT_DIR$`).

После запуска результат появится в `output.txt`.

Для сборки из терминала:

```bash
cmake -S . -B build
cmake --build build
```

## Формат входных данных

Одна запись на строку:

```text
ФИО;группа;номер_зачетной_книжки;оценка1 оценка2 оценка3 оценка4
```

Оценки должны быть целыми числами от 2 до 5.
